# OpenForge domain options — 2026-08-31

Checked on 2026-08-31 (Asia/Shanghai). Domain availability and promotional
pricing can change at any moment; a name is secured only after checkout
completes.

## Recommendation

1. **`openforge.network` — recommended.** It says exactly what OpenForge is,
   keeps the full project name, and remains broad enough for people, AI, tools,
   compute, channels, and every content field. Porkbun showed the name as
   available at its standard (non-premium) price: **US$4.63 for the first year,
   US$28.32 renewal**.
2. **`openforge.community` — strongest mission alternative.** It makes the
   human/community character explicit, but is longer and costs **US$8.24 for
   the first year, US$36.56 renewal**.
3. **`openforge.media` — strongest content alternative.** It communicates the
   broad AI-content scope clearly, but says less about the network mechanism.
   Pricing was **US$4.63 for the first year, US$36.56 renewal**.

Other names that returned no registry object at check time:

| Domain | First year | Renewal | Note |
| --- | ---: | ---: | --- |
| `openforge.studio` | US$11.84 | US$32.44 | Memorable, but sounds like one studio rather than an open network. |
| `openforge.global` | US$31.41 | US$77.75 | Broad, but materially more expensive to keep. |
| `joinopenforge.com` | US$11.08 base `.com` price | US$11.08 | Familiar `.com`, but adds a verb and is less canonical. |

`openforge.world`, `openforge.art`, `openforge.ai`, `openforge.org`, and
`openforge.cn` returned existing registration records in the live checks and
are not recommended as primary purchase targets. `openforge.com.cn` had no
matching CNNIC record, but registrar checkout was not confirmed, so it is not
ranked.

## Evidence and method

- Availability was checked with the registrar search and then cross-checked
  against the relevant registry RDAP endpoints. A `404` / no domain object was
  returned for
  [`openforge.network`](https://rdap.identitydigital.services/rdap/domain/openforge.network),
  [`openforge.community`](https://rdap.identitydigital.services/rdap/domain/openforge.community),
  [`openforge.media`](https://rdap.identitydigital.services/rdap/domain/openforge.media),
  [`openforge.studio`](https://rdap.identitydigital.services/rdap/domain/openforge.studio),
  and [`openforge.global`](https://rdap.identitydigital.services/rdap/domain/openforge.global).
- Pricing was read from Porkbun's official v3 pricing endpoint. See the
  [Porkbun API documentation](https://porkbun.com/api/json/v3/documentation).
- RDAP is the current standardized registration-data lookup mechanism. See
  [ICANN's RDAP overview](https://www.icann.org/rdap/).

## Purchase boundary

Domain registration creates a paid, renewable external asset in the buyer's
account. The recommended next action is to register `openforge.network` for one
year after the owner explicitly approves the price and registrar. After that,
the domain can be attached to the existing OpenForge Sites project and its DNS
records verified.
