# Community Providers

This directory catalogs independently maintained production projects and their
OpenForge adapter status. OpenForge does not vendor their source code.

| Provider | Role | Status |
| --- | --- | --- |
| [MoneyPrinterTurbo](moneyprinter-turbo/) | Short-video production | Adapter ready |
| [OpenMontage](openmontage/) | Agentic video production | Candidate |
| [ComfyUI](comfyui/) | Local/hosted workflow execution | Candidate |
| [VideoLingo](videolingo/) | Translation, subtitles, and dubbing | Candidate |

Run `openforge providers list` to inspect the machine-readable catalog. Read the
[community validation plan](../docs/community-validation.md) for the acceptance
criteria and contribution boundary.
